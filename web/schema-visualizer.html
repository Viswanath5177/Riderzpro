Multi-Dashboard Database Connectivity

All roles (Customer, Seller, Rider, Support Admin, Admin) live in ONE unified users table.

🧑 Customer App

Reads: Approved products, order status, rider delivery tracking.
Writes: Places orders, creates support tickets.

🏪 Seller Portal

Reads: Store products, stock levels, incoming orders.
Writes: Creates products (pending verification), accepts orders, marks ready for pickup.

🛵 Rider App

Reads: Assigned delivery task, pickup and dropoff addresses.
Writes: Updates status (picked_up, in_transit, delivered), streams live GPS location.

🎧 Support Admin

Reads: Pending products submitted by sellers, open customer tickets.
Writes: Approves/rejects products with notes, resolves support tickets.

🛡️ Super Admin

Reads: Platform-wide overview: all users, sellers, riders, orders, and products.
Writes: User activation/deactivation, global configurations.
